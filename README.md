# BAKI · UNDERGROUND

ต้นแบบ Roblox แนวต่อสู้ศิลปะการต่อสู้ในเมืองญี่ปุ่นยามค่ำ สร้างฉากและตัวละครด้วยชิ้นส่วน Roblox โดยไม่ต้องซื้อ asset หรือใช้ปลั๊กอิน

## เปิดเล่น

1. ดาวน์โหลด `BAKI-Underground.rbxlx` แล้วเปิดด้วย **Roblox Studio → File → Open from File**
2. กด **Play (F5)** และรอเมืองสร้างในช่วงเริ่มเซิร์ฟเวอร์ ฉากจะปรากฏเมื่อเริ่มเล่น ไม่ได้แสดงใน Edit mode
3. เดินไปสนามทางซ้ายหรือโดโจทางขวาเพื่อสู้กับ NPC เดินไปแผ่นสีแดง `ENTER THE ARENA` แล้วใช้ปุ่มที่แสดงเพื่อเข้าสนามใต้ดิน แผ่นสีฟ้าใช้กลับเมือง
4. ทดสอบแบบหลายคนด้วย **Test → Server & Clients → 2 clients** ก่อนเผยแพร่

หากต้องการเห็นฉากใน Edit mode ให้เปิด **View → Command Bar** แล้วรัน `require(game.ServerScriptService.BakiServer.World).Build()` จากนั้นบันทึกไฟล์ได้ ฉากถูกสร้างใหม่จาก `World.luau` ทุกครั้งที่เริ่มเซิร์ฟเวอร์ หากแก้ชิ้นส่วนใน Edit mode ต้องย้ายการแก้นั้นเข้า `World.luau` ด้วยเพื่อเก็บผลไว้

| การกระทำ | คอมพิวเตอร์ | คอนโทรลเลอร์ | มือถือ |
|---|---|---|---|
| ต่อย / คอมโบ 4 จังหวะ | คลิกซ้ายค้าง | X ค้าง | PUNCH ค้าง |
| ป้องกันด้านหน้า | F ค้าง | L2 ค้าง | BLOCK ค้าง |
| พุ่งตามทิศทางเดิน | Q | B | DASH |
| เดินทางเข้าสนาม | ปุ่ม ProximityPrompt | ปุ่ม ProximityPrompt | แตะ prompt |

## สิ่งที่มี

- เมืองพร้อมอาคาร ร้านค้า ไฟถนน ป้ายไฟ ต้นซากุระ และลานฝึก
- โดโจเปิดหน้า สนามประลองใต้ดินแบบอัฒจันทร์ล้อมวง และจุดเดินทางไปกลับ
- NPC 3 ระดับ ไล่ต่อสู้เมื่อเข้าใกล้ มีจังหวะเตือนก่อนโจมตีและเกิดใหม่หลังแพ้
- หมัด 4 จังหวะ หมัดสุดท้ายผลักคู่ต่อสู้ บล็อกด้านหน้า พุ่งหลบ และ stamina
- HUD เลือด พลังงาน ชื่อพื้นที่ สถิติ Strength/KOs ภารกิจชนะ 3 ครั้ง
- เอฟเฟกต์หมัด แอนิเมชันแขน และปุ่มสำหรับจอสัมผัส
- เซิร์ฟเวอร์ตัดสินคูลดาวน์ ระยะ สิ่งกีดขวาง ความเสียหาย และรางวัล

Strength เป็นคะแนนในเซสชัน ยังไม่มีผลเพิ่มความเสียหาย และยังไม่บันทึกเมื่อออกเกม ใช้ prompt ที่กระสอบในสวนเพื่อฝึก เพิ่ม Strength ครั้งละ 1 และใช้ stamina 10 การต่อสู้ผู้เล่นด้วยกันเปิดใช้งาน แต่ยังไม่มีรางวัล PvP หรือเขตปลอดภัย

## แก้ไขและสร้างไฟล์ใหม่

แก้ `src/server/World.luau` สำหรับฉาก, `src/server/Main.server.luau` สำหรับเกมเพลย์, `src/client/Controller.client.luau` สำหรับ HUD/เอฟเฟกต์ และ `src/shared/Config.luau` สำหรับค่าต่อสู้

```sh
cd /workspace/baki
python3 tools/build_place.py
python3 -m unittest discover -s tests -v
```

ใช้ Python 3 standard library เท่านั้น ไม่ต้องติดตั้ง package เพิ่ม หากใช้ Rojo อยู่แล้วสามารถใช้ `default.project.json` แทนไฟล์ที่สร้างได้

## ตรวจใน Studio ก่อนเผยแพร่

- Output ไม่มี error; ผู้เล่นเกิดบนแผ่นสีทอง เดินและกระโดดได้
- ใช้ prompt ที่กระสอบแล้ว Strength เพิ่ม 1 และ stamina ลดลง
- หมัดโดน NPC เมื่ออยู่ในระยะ และโจมตีผ่านกำแพงไม่ได้
- คอมโบครบ 4 ครั้งมีแรงผลัก; stamina ลดและฟื้น; พลังไม่พอจะพุ่งไม่ได้
- บล็อกลดความเสียหายเฉพาะด้านหน้าและใช้พลังงานจน guard แตก
- NPC ทั้งสามต่อสู้ แพ้แล้วให้รางวัลครั้งเดียว และเกิดใหม่ใน 10 วินาที
- ชนะครบ 3 ตัวได้โบนัส Strength 100 ครั้งเดียวต่อเซสชัน
- เข้าและออกสนามใต้ดินได้; ตายแล้วเกิดใหม่พร้อม HUD ที่ทำงาน
- ทดสอบ 2 clients และ mobile emulator แนวนอน ตรวจปุ่มต่อสู้ไม่ทับปุ่มกระโดด

ยังไม่ได้ทดสอบ runtime ใน Roblox Studio จากเครื่องคลาวด์นี้ เพราะไม่มี Roblox Engine จึงยังไม่รับรองเกมเพลย์ ประสิทธิภาพบนมือถือ หรือการเผยแพร่จริง ระบบตรวจฝั่งเซิร์ฟเวอร์เป็นพื้นฐานและยังต้องเพิ่มการตรวจการเคลื่อนที่ผิดปกติก่อนเปิดเกมแข่งขันจริง

## แนวทางและข้อจำกัด

ใช้แนวทางศิลปะการต่อสู้ เมืองยามค่ำ และสนามใต้ดิน ไม่ได้คัดลอกแผนที่ โค้ด หรือ asset ของ Ryujin การเข้าถึงเว็บ Roblox จากเครื่องนี้ถูกปฏิเสธ จึงไม่ได้ยืนยันภาพหรือรายละเอียดของเกมอ้างอิง ก่อนเผยแพร่ควรตรวจสิทธิ์ชื่อ Baki และเปลี่ยนชื่อ/ตัวละครเป็นของตนเองหากไม่มีสิทธิ์ใช้งาน

งานต่อยอดที่มีผลต่อคุณภาพจริง: แอนิเมชันต่อสู้ที่สร้างเอง เสียง ทดสอบสมดุลกับผู้เล่น บอสหลายเฟส ระบบเซฟ และการวัดประสิทธิภาพบนอุปกรณ์จริง ต้นแบบนี้ยังไม่ใช่เกมที่เผยแพร่แล้ว
